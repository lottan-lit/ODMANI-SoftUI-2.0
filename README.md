# ODMANI Soft UI 2.0

Leitor Android desenvolvido pela AUDMANI. Parceira editorial: Lottan.

## Baixar o APK de teste

**[Abrir o site e baixar no celular](https://lottan-lit.github.io/ODMANI-SoftUI-2.0/#download)**

APK **2.1.0-alpha07**, código **10**, Android 8 ou posterior. Versão, tamanho e SHA-256 estão em `web/assets/release.json`. Build Debug com a mesma assinatura da alpha06.

## Organização e versões

- `web/`: site público, capturas reais e APK aprovado para download.
- `android/`: fontes Android da versão aprovada **2.1.0-alpha07 / código 10**, correspondentes ao APK publicado.
- `docs/`: documentação; as notas antigas são registros da versão de origem.
- `.github/workflows/pages.yml`: publica exclusivamente o conteúdo de `web/`.
- O fluxo antigo de importar fontes é legado; não é necessário para publicar o site.

Fontes finais e APK aprovados publicados. Chaves, credenciais, PDFs pessoais, configurações locais, caches e dados dos emuladores não são incluídos. Para compilar, consulte `android/README.md`.

## Instalação e atualização

Abra o site no celular, toque em Baixar APK de teste e siga as instruções do Android. Atualizar uma instalação existente exige certificado compatível. Evite desinstalar para preservar documentos e histórico.

Na alpha07: uma compilação concluída, inspeção visual e seleção por toque dos seletores de duas, três e quatro opções no emulador Android 15. Esta correção não reexecutou auditoria geral nem testes de funcionalidades não relacionadas. Sem teste em aparelho físico nesta rodada.
